# Triage

Move incoming Issues through the triage roles defined in `docs/agents/triage-labels.md`. `docs/agents/issue-tracker.md` determines which tracker objects are request surfaces; Saki does not route external pull requests through this state machine.

Every GitHub comment posted by this skill starts with:

```text
> *This was generated by AI during triage.*
```

## DSH compatibility preflight

Before posting, labeling, closing, or writing an out-of-scope record:

1. Confirm `read`, `write`, `edit`, `glob`, `grep`, and `skill`, plus one of `bash` or `pwsh`.
2. Resolve `git` and `gh`, confirm the checkout with `git rev-parse --show-toplevel`, then run `gh auth status`.
3. Run `gh repo view -R BreakfastDaPaiDang/saki --json viewerPermission` and `gh label list -R BreakfastDaPaiDang/saki --limit 200`.
4. Read the tracker and triage-role documentation.

Stop before mutation when a capability, command, authentication, permission, or role label is missing, and state the corrective action. Use `-R BreakfastDaPaiDang/saki` on every `gh` command.

## Process

1. Read the complete Issue, comments, labels, author, and dates. Check prior triage notes.
2. Search the repository by domain concept for an existing implementation and inspect `.out-of-scope/` when it exists.
3. Recommend one category and one triage role with evidence, then wait for maintainer direction.
4. Verify the claim through the closest observable interface. Report confirmed, not reproduced, or insufficient information.
5. If decisions remain, load `grilling` and `domain-modeling` with the DSH `skill` capability.
6. Apply the authorized result. A `ready-for-agent` transition includes a brief following [AGENT-BRIEF.md](AGENT-BRIEF.md). A rejected enhancement follows [OUT-OF-SCOPE.md](OUT-OF-SCOPE.md); an already implemented request does not.

Conflicting triage roles require maintainer resolution. A direct maintainer override may skip the interview, but moving an Issue to `ready-for-agent` still requires a self-contained brief unless the maintainer explicitly declines one.
